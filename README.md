# Chasm 天坑奇观 —— 定制模组（v0.3.0）

目标平台：Minecraft 1.21.1 + NeoForge 21.1.252（你的 FCL 实装版本），JDK 21 构建。
依赖：Create（机械动力）6.0.x 为必需。

## 一、功能总览

### v0.1 已有功能
1. 坐骑速度：马/驴/骡/骆驼/羊驼/行商羊驼/猪/炽足兽/骷髅马/僵尸马 逐种倍率，config/chasm.toml 可调。
2. 强力胶强化：耐久无限（默认组件改造）+ 使用距离无上限（持胶时提升交互范围属性），可配置。
3. 飞行药水：缓降药水+幻翼膜=30分钟；再+红石=2小时。喷溅/滞留/药箭齐全，图标 Fly.png。
4. 天坑结构：主世界随机生成（详见下方 v0.3 形状系统），噪声边缘、按群系的崖壁条纹与
   底部生态（熔岩海/繁茂洞穴/幽匿/珊瑚/沙漠等）、水瀑/藤蔓/沙柱/悬空残骸装饰、
   海洋权重×3、出生点保护、频率≈或低于远古城市。
5. 本地 mp3 背景音乐：放入 config/chasm/music/ 随机插播，概率/音量/间隔可调；/chasm music 控制。

### v0.2 新增功能
6. 鞘翅合成：幻翼膜/下界合金锭/幻翼膜 + 幻翼膜/末影之眼/幻翼膜 + 幻翼膜/空/幻翼膜。
7. 长效烟花：1 纸 + 1~8 火药（原版只到 3），飞行时间 1~8 逐级增加。
8. 无限附魔（endless_boost）：烟花可用附魔台/附魔书获得；使用后持续推进直到落地。
9. 强加速烟花：任意烟花 + 1~8 火药 = 该烟花 boost_level 1~8（保留飞行时间与颜色），
   使用瞬间给鞘翅更强速度加成，等级越高越快。
10. 收割作物概率掉落：钻石 0.2%、下界合金锭 0.1%（默认，0.1%~1% 可调），
    范围 = #minecraft:crops + 可配置额外方块（默认含甘蔗/仙人掌/下界疣/可可豆）。
11. /chasm adv 诊断：显示已加载进度数、选项卡数、数据包进度文件数，
    用于排查"进度选项卡显示不全"（见常见问题）。

### v0.3 新增/变更
12. 涌现式天坑形状（重构）：形状不再是"抽奖换形状"，而是种子驱动的形状场——
    基础包络(圆/纺锤) × 谐波层 × 特征分量。大部分天坑呈圆或裂口(纺锤)型；
    约 10% 的异常种子叠加心形/星形/方形特征分量，涌现出酷似特殊形状的轮廓
    （彼此各不相同，有的"恰好像"心形）。边缘噪声扰动保留。
    config 三种模式：
    - shape_mode = "emergent"（默认，如上）
    - shape_mode = "fixed"（所有天坑都是 fixed_shape 所选形状：circle/spindle/square/heart/star）
    - shape_mode = "pool"（v0.2 旧概率池行为，兼容）
13. 天坑 × 原版结构联动：符合条件的坑底有概率生成——
    废弃村庄遗迹（坑半径≥12、非海洋，含枯灌木点缀，不含村民）、
    远古城市中心（坑深≥40，附带幽匿蔓延）、水下遗迹（仅海洋天坑，自动灌水）。
    每坑最多 1 个（max_structures 可调），全部概率在 [sinkhole_structures] 节配置。
    海洋神殿不支持：其为硬编码结构，无模板可复制（已用水下遗迹替代）。

## 二、构建（Windows，推荐云电脑）

1. 把本 zip 完整解压到一个文件夹（重要：不要在 zip 里直接双击）。
2. 双击 build.bat，等待自动下载 JDK 21 + Gradle 8.10.2 + NeoForge 依赖（约 600MB）。
3. 成功后产物在 build\libs\chasm-0.3.0-all.jar。
4. 把该 jar 复制到手机 FCL/.minecraft/versions/1.21.1-NeoForge/mods/。

若窗口闪退：在文件夹地址栏输入 cmd 回车，再输入 build.bat 回车，把报错截图发回。
首次运行建议耐心等待（下载+构建 10~30 分钟不等）。

## 三、配置

首次进游戏后自动生成 config/chasm.toml（含中文注释，改完重进世界生效）。
music 目录需手动创建：config/chasm/music/，放入 .mp3 文件即可。

## 四、常见问题

Q1 进度选项卡显示不全？
   先运行 /chasm adv：若"文件数"明显大于"已加载数"，说明部分进度文件加载失败
   （多为模组间物品/条件引用缺失），把 logs/latest.log 中 "Couldn't load advancement"
   相关报错发回，可针对性修复；若两数一致则属于界面布局问题，同样反馈即可。

Q2 天坑只在未探索区域生成，用 /locate structure chasm:sinkhole 找。
   想看固定形状效果：把 shape_mode 改为 "fixed"、fixed_shape 改为想要的形状。

Q3 强力胶改动对已有物品也生效（重进世界后拾取/使用时刷新）。

Q4 音乐仅单人模式生效；与 NetMusic 互不干扰。

## 五、已知限制

- 天坑最长轴受游戏结构系统限制约 16 区块（配合重尾分布观感近似更大）。
- 联动结构只会在天坑中心区块内放置（保证不被后续雕刻覆盖），规模为"遗迹"级别。
- 代码未经真机编译验证，若构建报错请把错误发回（项目按 1.21.1 官方映射编写）。
- 配置 GUI 暂未提供，直接用文本编辑器改 chasm.toml。

## 网络问题（重要）

构建需要从 maven.neoforged.net 下载 NeoForge 依赖。该站点在中国大陆网络下经常被阻断（连接重置/超时），表现是构建报 "plugin ... was not found" 或下载卡死。

- build.bat 已内置网络预检：若检测不到会直接提示，而不是报出误导性的错误。
- 解决方法（任选其一）：
  1. 租云电脑时选择**香港 / 新加坡 / 日本 / 美国西部**节点；
  2. 在云电脑上开启代理 / VPN 后再运行 build.bat；
  3. 换一台能直连海外网络（如挂好代理的家用电脑）的机器构建。
- 构建成功后得到的 jar 是通用的，拷回手机即可，手机不需要访问该站点。

## 在线构建（免代理 · 大陆网络推荐）

大陆网络访问 maven.neoforged.net 经常被连接重置，本地构建可能报
"plugin ... was not found"。推荐改用 GitHub Actions 免费在线构建：

1. 注册/登录 GitHub（github.com，免费账号）
2. 右上角 + 号 → New repository → 名字随意（如 chasm-mod）→
   Public → Create repository
3. 进入仓库 → Add file → Upload files → 把 chasm-mod 文件夹里的
   全部内容（包括 .github 文件夹）拖拽上传 → Commit changes
   （.jdk / .gradle-dist / .gradle 三个本地文件夹不用上传）
4. 上传完成后构建自动开始：仓库页 → Actions 标签 → 点 build
   运行记录查看进度（约 3~8 分钟）
5. 成功后页面底部 Artifacts → chasm-mod → 下载 zip
6. 解压得到 chasm-0.3.0-all.jar → 放入手机 FCL 的 mods 文件夹

若 github.com 打开缓慢：在第 5 步下载链接前面加 https://gh-proxy.com/
前缀即可加速。以后代码更新：重新上传覆盖文件即可触发新构建。
